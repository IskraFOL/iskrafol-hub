## Обратная связь

В опубликованном index.html добавлен отдельный скрипт для существующей формы FormSubmit.
При включённом JS используется официальный AJAX API (без перехода в новую вкладку):
- нажатие «Отправить» ≠ успешная доставка;
- сообщение о принятии показывается только после положительного JSON-ответа сервиса;
- текст сохраняется при отказе, ошибке сети или таймауте;
- запасной способ отправки открывается только по отдельному нажатию игрока;
- защита от двойного POST, интерфейс RU/EN;
- исходная HTML-форма работает без JavaScript.

**Проверки:** 6 функциональных сценариев в модели DOM PASS и синтаксис обоих JS PASS.
**Ограничение:** реальный тест доставки письма не проводился — необходимо наблюдение на рабочей почте. Отсутствие писем пока НЕ означает отсутствие обращений.

## Посещения и статистика

Подготовлено подключение Cloudflare Web Analytics без смены GitHub Pages, DNS, сайта, фото, Tracker или существующего React.

**ЗАВИСИМОСТЬ:** до момента выдачи владельцем публичного Cloudflare Web Analytics Site Token загрузчик выключен и данные о посещениях НЕ собираются. Никаких ложных счётчиков не выводим. Прошлые посещения задним числом не восстановить.

Для активации владелец должен открыть https://dash.cloudflare.com/ →
Analytics & Logs → Web Analytics → Add site → hostname искраfol github адрес (точное значение: iskrafol.github.io) → получить Site Token 32 hex → внести его в публичный assets/fol-site-analytics.js. Важно: нужен Site Token, а НЕ API Token или пароль.
После активации проверить загрузку beacon и данные в панели Cloudflare.
