## Обратная связь

В опубликованном index.html добавлен отдельный скрипт для существующей формы FormSubmit.
При включённом JS используется официальный AJAX API (без перехода в новую вкладку):
- нажатие «Отправить» ≠ успешная доставка;
- сообщение о принятии показывается только после положительного JSON-ответа сервиса;
- текст сохраняется при отказе, ошибке сети или таймауте;
- запасной способ отправки открывается только по отдельному нажатию игрока;
- защита от двойного POST, интерфейс RU/EN;
- исходная HTML-форма работает без JavaScript.

**Проверки:** 6 функциональных сценариев в модели DOM PASS и синтаксис обоих JS PASS.
**Ограничение:** реальный тест доставки письма не проводился — необходимо наблюдение на рабочей почте. Отсутствие писем пока НЕ означает отсутствие обращений.
