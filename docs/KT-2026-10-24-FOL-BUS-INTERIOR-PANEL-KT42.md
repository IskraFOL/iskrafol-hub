Предыдущие тесты #57 на четыре направления: GitHub Actions [39055209815](https://github.com/Anwite/four_old_legends/actions/runs/39055209815) **success**. Поздний прогон [39055896397](https://github.com/Anwite/four_old_legends/actions/runs/39055896397) **failure** на этапе запуска Minecraft / переходов меню, то есть не подтверждает неисправность дискового сохранения коллизий и не является PASS на финальной #61.
- Интеграционная ветка **#86** содержит пять интерьерных блоков/предметов: малый стол, большой стол, стул, чашку и фоторамку. У большого стола одноблочное хранение с коллизией шириной около двух блоков; соседние клетки проверяются только при ручном размещении. При размещении из NBT эти проверки обходятся; требуется проверка проходов и мебели.
- По документации и проверочным скриптам PR **#79–81** в обычной пятиэтажке предусмотрены **20 больших столов**, в двух вариантах руин Лика — по **8**. Девять NBT прошли описанную ранее статическую проверку палитр `Name/Properties`. **Автоматическая естественная генерация этих NBT не обнаружена** в проверенных точках интеграции, /place template есть для тестирования.
- Фоторамка сохраняет UUID установившего игрока; у NBT-рамок без UUID рендер задуман как изображение текущего игрока. Необходимо испытание рендера и сохранений.

## Интеграционное расхождение
- В цепочке остановки `OldLegends.java` регистрирует `ModBlocks`; в цепочке #86 он регистрирует `ModInteriorBlocks` и BlockEntity.
- В `LegendCommands.java` остановки — `/legends bus_stop`, в #86 — `/legends interior test`.
- `LikLegend.java` совпадает побайтово в сравниваемых ветках; повторно его менять не требуется.
- Выбор одной ветки без аккуратного переноса функциональности другой приведёт к потере части реализации. **Слияния не проводились.**

## Остаточные риски
1. Переустановка остановки с другой ориентацией на том же якоре может быть отвергнута из-за строгого сравнения `BlockState`.
2. Предполагаемые коллизионные блоки не проверяются явно на `isLoaded` при размещении; проверить границы чанков.
3. 138 физ. элементов, 3 надписи и сохранение после выхода — ещё не подтверждены на финальной ветке.
4. Большой стол из NBT может пересекать мебель/стены — игровой тест обязателен.
5. Совместное совмещение автобусной и интерьерной веток JDK25 / Minecraft 26.3: **NOT RUN**.
