# КТ 18.10.2026 — живой счётчик скачиваний Modrinth на сайте Four Old Legends

**Статус:** только согласованная **идея для бэклога** — владелец попросил **зафиксировать, пока не реализовывать**. Никаких изменений кода сайта, веток сайта, сборки, PR, GitHub Actions, `main` или продакшена.

## Идея

На действующем публичном сайте Four Old Legends (React/TypeScript + Vite, размещён через GitHub Pages) вывести **живое количество скачиваний на Modrinth**, чтобы не обновлять число вручную. Последнее названное владельцем количество: **1 119**; это историческое наблюдение, **не постоянно актуальная цифра**.

План будущей реализации, подлежащий проверке:
- Читать общий счётчик `downloads` проекта из публичного Modrinth API v2 (`GET /v2/project/{project_id_or_slug}`). Точный ID/slug перед разработкой проверить по официальной странице, не полагаться на непроверенный идентификатор из чата.
- Отображать ясно подписанное значение: **«Скачиваний на Modrinth»**, а не общее число со всех платформ.
- Запрашивать при открытии и периодически обновлять приблизительно раз в 10–15 минут; не дёргать API при каждом рендере.
- Ошибка или отсутствие сети: показывать нейтральный текст «Статистика временно недоступна» либо скрывать цифру. **Не показывать старые 1 119 как якобы живое значение**.
- На счётчике или рядом ссылка на официальный Modrinth. Никакого бэкенда или GitHub Actions для периодического обновления не требуется, если публичный API допускает браузерные запросы; проверить это во время реализации.
- Сохранить уже существующую рамку благодарности **за 1 000 скачиваний** как исторический рубеж, не заменять её текущим числом. Дизайн — неброский счётчик без динамичных конфетти/анимаций.
- Число CurseForge не складывать с Modrinth без явно обозначенной методики и желания владельца.
