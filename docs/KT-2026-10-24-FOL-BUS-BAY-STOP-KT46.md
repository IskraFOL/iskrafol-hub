## Что реально сделано

1. Из одобренного ранее [Draft #61](https://github.com/Anwite/four_old_legends/pull/61) в рабочую ветку скопирован `BusStopPhysicsLayout.java` (138 физических фрагментов); `RoadBusBayShelterSafety.java` выполняет предварительную проверку **всего** физического навеса над будущим карманом.
2. Модель и блоки остановки сохранены: `ModBlocks`, `BusStopCollisionBlock`, `BusStopPhysicsLayout`, JSON для коллизий и `bus_stop_display.json`; 6/6 исходных SHA побайтово равны проверенным файлам из #61. `BusStopBuilder` перенесён полностью с дополнительным точечным rollback-методом.
3. `OldLegends.java` теперь регистрирует физический тип до создания мира в экспериментальной ветке.
4. `RoadBusBayStopBuilder.placeCreativeTest` создаёт снимок BlockState и после общего preflight пробует разместить карман, затем остановку; при штатной ошибке очищает частично созданные коллизии/Display и восстанавливает изменённые клетки кармана. **Crash/restart после аварии не защищён.**
5. Команды теста:
   - `/legends road bay preview <x> <y> <z>` — читает блоки, не меняет мир;
   - `/legends road bay test <x> <y> <z>` — изменяет мир, **только Creative + allowGriefing=true**.
   Параметры — **NBT-якорь первого прямого сегмента**, направление — ориентация игрока.
6. Независимая геометрическая сверка исходника `BusStopPhysicsLayout`: все четыре стороны — 138 физических клеток, 35 клеток фундамента внутри 50 клеток платформы. **4/4 математической проверки**, не gameplay PASS.
7. Старый ЛиАЗ при подтверждённом согласовании: маршрут **124**, последний рейс в табличке **23:44**, приезжает по точкам, замедляется, открывает двери, стоит и уезжает. Конкретные модификация и окраска **не утверждены**; не подменять случайным референсом. Полноценное управление игроком в текущий scope **не входит**.

## Открытые блокеры

- JDK25, Gradle и Minecraft 26.3 **NOT RUN**. В реальном мире не проверено ни выполнение команды, ни транзакционный откат, ни повторный вход.
- Карман пока только левый (локальный X>8), правостороннее безопасное зеркалирование не реализовано; авто-генерация не подключена.
- Происхождение дороги по одним BlockState строго не доказано: в личном мире игрока использовать не следует, только новый одноразовый Creative-мир.
- Нужны реальные сценарии отказа: BlockEntity, вода, дерево/постройка, отсутствие загруженных чанков, ошибка остановки после готового кармана, Save & Quit/restart.
- Визуальная и физическая модель ЛиАЗа (корпус, салон, окна, двери, серверная Entity, анимация) и его путь в реальном Minecraft **не сделаны**, пока только математика Draft #90.
- Сквозная интеграция Roads #72 / интерьер #86 / остановка #92 / автобус #90 / диктофон #88 не завершена.
- `main` не менялся; никаких слияний без разрешения владельца; GitHub Actions не запускались.
