# КТ 53 — Four Old Legends: подготовка озвучки и концепция коротких видео

**Дата:** 25 октября 2026 г.  
**Статус:** зафиксированы решения и идеи, **реализация / игровые тесты отсутствуют**.

## Озвучка исследователя

- Для записи голосовых реплик выбран **Audacity** как основной бесплатный редактор для Windows; **Ocenaudio** возможен как упрощённый вариант. Никакой платной подписки для стартовой работы не требуется.
- У пользователя **два микрофона**: микрофон гарнитуры и отдельный USB-микрофон (модель последнего пока неизвестна). Для сравнения запланированы короткие чистые записи на оба устройства, без шумоподавления и эффектов.
- Стартовые рекомендации: моно, 48 кГц, WAV без потерь (если устройство позволяет — 24-bit PCM), целевые пики ~−12…−6 dBFS, расстояние около 15–20 см, микрофон немного сбоку для защиты от взрывных согласных.
- После пользовательского теста сравнить шум, разборчивость и естественность, затем отдельно сделать атмосферную обработку под старый диктофон. Исходную чистую дорожку сохранять всегда.
- **Ни одна актёрская пользовательская запись ещё не получена, финальная озвучка не создана, ничего в мод не интегрировано**. Ранее созданные простые TTS-демо не считать финальным голосом исследователя.
- Для истории исследователя действуют прежние сюжетные и интонационные ограничения. Русская речь первична; английские субтитры — отдельный этап.

## Видео: новая идея для обсуждения

Пользователь спросил о возможности производства трейлеров Four Old Legends, мини-фильмов и серий коротких вертикальных роликов в формате Shorts. Пока **идея для обсуждения**, не утверждённое ТЗ и не начало производства. Реалистичный потенциальный процесс:
1. Сценарий, раскадровка, режиссёрский/монтажный план, монтаж игрового footage / пользовательских видео / кадров, титры, звук.
2. Вывод законченного MP4 в вертикальном 9:16, горизонтальном 16:9 и другие форматы по необходимости.
3. Для полностью новых сложных кинематографических видео без исходных кадров потребуется специализированный видеогенератор или 3D-сцены; обычный монтаж существующих записей не является генерацией реалистичного игрового кино с нуля.
4. Выпуск роликов и публикация в соцсети — только после согласования; авторские права на используемые ресурсы и музыку соблюдать.

**Не расширять план версии FOL 1.3.0** за счёт роликов или новых музыкальных механик. Направление OST: инструментальный саундтрек потенциально для версии 1.3.0 после оценки и утверждения; v0.3 «Кто-то помнит» остаётся черновиком на паузе; песни/кассеты — будущие идеи 2.0.0.
