## Реализовано в исходниках
- Новый маршрут `#/tracker`, ссылки в навигации и на главной.
- Публичный модерируемый каталог известных ошибок: фильтры статуса, категории и версии, поиск по ID и RU/EN текстам, сортировка по последнему обновлению, счётчик и пустые состояния; адаптивная вёрстка.
- Состояния: зарегистрировано, подтверждено, в работе, на проверке, исправлено в **опубликованном** релизе, закрыто с причиной; валидатор непротиворечивости дат/ID/переводов/ссылок.
- **Пустой каталог на старте осознанный**, чтобы не показывать неутверждённые внутренние проблемы или вымышленные записи как реальные. Наполнение после редакторской приёмки.
- Расширенная **единая** FormSubmit-форма для главной и трекера: дифференциация bug/idea/other, версия мода/игры/Fabric, ОС, шаги, фактический/ожидаемый результат, частота, необязательная HTTPS-ссылка.
- Сохранены текущая форма и её endpoint, `_url`, `_next`, две локализации RU/EN, тема, прочие hash-маршруты, живой счётчик Modrinth, благодарность за 1000 и Полевой журнал.
- Добавлен тестовый скрипт `npm run test:tracker` с проверками каталогов/сортировок/безопасности статусов. Тесты — **подготовлены, не выполнялись**.
