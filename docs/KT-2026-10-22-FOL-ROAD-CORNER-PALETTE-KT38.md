# КТ 38 — Four Old Legends: исправление NBT-палитры road_corner

22.10.2026, продолжение КТ 37. [Draft PR #86](https://github.com/Anwite/four_old_legends/pull/86).

## Причина
Сверка реальных дорожных NBT обнаружила несовместимые с форматом структур Java 26.3 поля в `road_corner.nbt`: `id/properties` вместо `Name/Properties`. Другие два шаблона имеют верные имена ключей, но более ранний DataVersion 4790, который не меняли без игрового подтверждения.

## Исправлено
- Переписаны **только поля 18 записей палитры** `id→Name`, и 14 наборов свойств `properties→Properties`.
- **Одно дополнительное поле `id` вне палитры сохранено**. Попытка заменить все вхождения была отклонена до записи в GitHub.
- Размеры 13×8×17, число 1768 блоков, их координаты, состояния и DataVersion 5023 сохранены.
- GZIP CRC32/ISIZE и побайтовая эквивалентность после повторной упаковки проверены.
- Повторный readback из GitHub по blob SHA `8ebcc74ecc1e103f5f6575e512674b3655581ccd`: **18 Name, 14 Properties, 1 внешнее id, 0 старых свойств в палитре**.
- Добавлен `scripts/check_road_palette_format.py`.

## Проверка
На первоначальных NBT доказаны **24/24 стыка** (Y=0; 6 соседних пар и 0 пересечений); переименование палитры не меняет блочную геометрию. Реальная загрузка Minecraft 26.3, Java25/Gradle и приёмка по-прежнему **NOT RUN**.

Main без изменений, PR остаётся Draft. Release First.
