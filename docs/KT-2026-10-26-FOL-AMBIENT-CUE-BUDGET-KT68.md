# КТ68 — Four Old Legends: общий ритм атмосферных сигналов

Дата: 26 октября 2026. Реализация: [FOL Draft PR #108](https://github.com/Anwite/four_old_legends/pull/108), отдельная ветка `fix/ambient-cue-budget-kt68-2026-10-26` от [KT67 PR #107](https://github.com/Anwite/four_old_legends/pull/107). Main не менялся.

## Причина и результат

Даже после исправления выбора легенд звук, шёпот, стингер и шаги за спиной могли запускаться независимо из трёх директоров. Добавлен общий `AmbientCueBudget`: не чаще одного **выразительного** атмосферного сигнала на игрока за **80 тиков (4 сек)**. Фоновый ритм сердцебиения (`WARDEN_HEARTBEAT`) под этот ограничитель не попадает.

Общий бюджет получают `AmbientDirector`, `AmbientSoundDirector` и `PhantomSoundDirector`. История по UUID очищается при выходе игрока и новом мире без изменений SavedData. Неудавшийся запрос бюджета тихо пропускает эффект, не создавая асинхронных очередей.

Сюжетные `LegendaryMeetingEvent`, `LikChroniclerEvent` и активная вражда `FeudDirector` имеют приоритет, случайные атмосферные звуки во время них не исполняются. Настройка `ambientEnabled=false` теперь отключает и второй `AmbientDirector`; для звуков за спиной по-прежнему действует отдельная `phantomSoundEnabled`.

**Не затрагивались:** накопление напряжения, содержимое легенд, NBT, старые события, SavedData и запрет руин Лика из КТ66.
