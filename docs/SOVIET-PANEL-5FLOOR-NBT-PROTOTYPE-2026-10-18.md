# КТ — советская панельная пятиэтажка: первый реальный Minecraft NBT

**Дата:** 18.10.2026
**Проект:** Four Old Legends, Minecraft Java 26.3
**Авторизация:** пользователь согласовал создание реалистичной советской многоэтажной постройки по архитектурным референсам, с детализированным экстерьером и интерьерами, как у уже реализованной остановки.

## Что фактически создано

Построена **программно настоящая бинарная .nbt-структура Minecraft Structure Template**, не текстовая заглушка и не изображение. Файл передан пользователю в том же чате как скачиваемый артефакт:

- `soviet_panel_five_storey_26_3.nbt` — 43 980 байт, gzip-NBT, 42 × 23 × 23 блока.
- `soviet_panel_five_storey_README.md` — инструкция теста в Minecraft через Structure Block, меры предосторожности, описание.
- `generate_soviet_5floor.py` — воспроизводимый генератор структуры на Python с комментариями на русском.
- `soviet_panel_five_storey_26_3_package.zip` — пакет NBT + README + генератор, проверен на целостность.
- **Файлы доступны как артефакты в текущей беседе, ещё не добавлены бинарно в GitHub-репозиторий мода.** Не выдавать GitHub-документ за скачиваемую копию бинарного NBT. Если потребуется Git-интеграция, сначала проверить файл в игре и добавить его в отдельную ветку с реальными байтами.

## Архитектура, внешний вид и интерьеры

Ориентир — типовая советская панельная серия **1-464** (пятиэтажная, без лифта, по четыре квартиры на этаже в каждом подъезде), но **это авторская Minecraft-адаптация**, а не точный архитектурный план/обмер реального дома.

- **Два подъезда, пять этажей, 40 квартир**; 40 комплектов кроватей, по четыре входа в квартиры на каждой площадке подъезда.
- Реальные лестничные пролёты между этажами, с промежуточными площадками; 8 лестничных переходов на два подъезда.
- Панельные фасады, межпанельные швы, стык секций, следы старения, двухъярусные окна, балконы второго–пятого этажей, плоская крыша с парапетом и вентшахтами.
- В квартирах: перегородки, кухня/уголок с печью, раковиной/котлом, комнаты с мебелью, кровати, книги, декоративный свет; прихожие и коридоры.
- Весь шаблон вписывается в 42×23×23 (ось X <48); палитра из 38 состояний и 16 298 записей блоков (включая воздух внутри корпуса).

## Техническое подтверждение

- Minecraft 26.3 использует `DataVersion=5023`, палитра состояний — поля `id` и `properties`. Проверено по официальным заметкам Mojang и версии `PrismarineJS/minecraft-data`.
- Готовый бинарный gzip-NBT **независимо прочитан обратно** Python-декодером: корректны корневые теги, размер, вся палитра, индексы блоков и список сущностей. Проверка дополнительной геометрии подтвердила все 40 квартирных дверей, 32 балконные двери, 8 лестничных переходов.
- **НЕ проводилась загрузка шаблона настоящим Minecraft 26.3, проверка прохода, взаимодействия дверей, лестниц, освещения или балконов в игровом мире**. Не объявлять игру проверенной только по бинарному аудиту.

## Тестирование и интеграция, только после согласования

1. Использовать **копию тестового мира**, так как воздух и конструкции NBT перезаписывают блоки в зоне размещения. Нужна большая ровная площадка вдали от построек и дороги.
2. Скопировать NBT в `<save>/generated/minecraft/structures/soviet_panel_five_storey_26_3.nbt` и загрузить обычным Structure Block `minecraft:soviet_panel_five_storey_26_3`. Пользователь предпочитает тест в Minecraft из IntelliJ кнопкой Play, **не гонять терминал**.
3. Проверить все этажи, проходимость лестничных пролётов, двери, балконы, комнаты, корректность палитры/деталей. Попросить скриншоты/координаты проблемы и поправить источник генератора.
4. Только после приёмки — добавить реальный бинарный NBT под `src/main/resources/data/oldlegends/structure/` в **отдельную feature-ветку**, подготовить Draft PR, но не сливать `main` без разрешения. Не добавлять огромное здание в спонтанную генерацию без отдельного ТЗ и безопасного выбора площадки.

**Примечание:** предыдущая договорённость по канону сохранена: исследовательский контент допустим, расхождения между мирами / мультивселенная НЕ канон. Сам дом пока демонстрационный исследовательский объект, без утверждённых сюжетных загадок и механик.
