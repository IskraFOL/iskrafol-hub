# Wolfenstein 2009 — W09-КТ11: найдена настоящая строка субтитров в assets.pk4

**Дата:** 24.10.2026. Продолжение КТ09–10 по редактированию вступительного диалога «Фермы» на оригинальном движке Wolfenstein 2009. Пользователь прислал файл `assets.pk4` (21 178 936 байт).

## Результат исследования пользовательского assets.pk4

Это ZIP-подобный PK4 с **6 421 записью**. Обычный Python `zipfile` не открывает его, потому что ZIP-окончание EOCD имеет игровую сигнатуру `02 0A 53 48` вместо `PK 05 06`. Поля EOCD при этом валидны: 6421 entry, каталог на offset 20603920, длина 574994; замена **только сигнатуры** в временной копии позволила прочитать **все 6421 файла, ZIP `testzip()` PASS**. Исходный пользовательский архив не переписывался.

Обнаружено **семь языковых файлов**:
`strings/english.lang`, `french.lang`, `german.lang`, `italian.lang`, `polish.lang`, `russian.lang`, `spanish.lang`.

**Точная реплика из фильма пользователя**:
- `strings/english.lang`, `#str_000356`: `This is ridiculous. Why in hell are we guarding a farm?`
- `strings/russian.lang`, `#str_000356`: `Это смешно. Какого дьявола мы охраняем ферму?`

Это точно соответствует русскому субтитру из видео «тестфермы(3).mp4» КТ10 и исходной строке `mDebugText` в `brains/farm/start_conversation.brain` КТ09. Не доказано, что изменённый в `mDebugText` текст автоматически влияет на экранные субтитры — теперь установлено существование отдельного языкового ключа.

**Дополнительные важные находки**:
- `scripts/maps/farm.script` — 21 104 байта, **человекочитаемый** сценарий миссии: `namespace map_farm`, `sys.trigger()`, `sys.wait()`, `cavernLift()`, `elevatorDrop()` и другие функции. Это отдельный путь к исследованию игрового сценария, не равнозначный двоичному `.brain`.
- `def/voice/scripted_voice.def` содержит ссылку `"lipsync_farm_0501_wi1" "farm_0501_wi1_stream"` в `entityDef scripted_voice_wi1_farm` и `detailPack "streampacks/scripted_voice_wi1_farm.spk"`. Это связь с отдельным ресурсом озвучки, не прямое подтверждение полного пути аудиоданных в пользовательской установке.

Целевой `strings/russian.lang` перепакован deflate raw, корректно обновлены CRC и размеры **этой** записи, центральные смещения **поздних** записей и указатель на каталог в EOCD. **Нестандартная EOCD сигнатура сохранена**; остальные локальные данные архивных членов скопированы без перепаковки. Проверка всех 6421 записей через временно нормализованную для проверки копию ZIP: **PASS CRC и точного соответствия 6420 остальных файлов**.

## Границы и проверка

- **Игровой тест нового assets.pk4 НЕ выполнен.** Внутренняя ZIP-валидность не доказывает принятие движком.
- Пользователь должен закрыть игру, сохранить оригинальный `assets.pk4`, заменить **только** в тестовой установке, запустить «Ферму» сначала и сравнить первую русскую реплику. При сбое вернуть оригинал.
- **.brain, модели, текстуры, voice/spk, русская озвучка, физика, геометрия, Havok, миссии** в этом эксперименте не изменены.

- По ходу работы не разрабатывался новый общий конвертер: выполнен узкий проверенный однострочный патч пользовательского архива с изменением одного участника.
