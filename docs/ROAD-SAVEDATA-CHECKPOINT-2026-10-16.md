# КТ — дороги и изоляция сохранений, 16 октября 2026 года

**Проект:** Four Old Legends · **версия мода:** 1.3.0 в разработке, аудит будущей 2.0.0.  
**Контрольная точка:** проверенная интеграция исправлений дорожных стыков и защита дорожных SavedData при смене одиночных миров.

## Слито в `main`

1. [PR #23 — объединение исправлений дорожных стыков](https://github.com/Anwite/four_old_legends/pull/23), merge `e999980b`:
   - восстановлены правильные якоря NBT-структур и опорные координаты поворотов;
   - статический NBT-тест: 24/24 стыков с шестиблочным покрытием по четырём направлениям;
   - ранее получены игровые снимки семи сегментов из Superflat/Creative теста.
2. [PR #25 — ограничение ресурсоёмкого CI](https://github.com/Anwite/four_old_legends/pull/25): дорожные снимки/тесты не запускаются на посторонние PR.
3. [PR #26 — изоляция дорожного состояния и защита SavedData](https://github.com/Anwite/four_old_legends/pull/26), squash merge [`cae6143`](https://github.com/Anwite/four_old_legends/commit/cae6143cfc9261e42ed9982a431e00432fac1d89):
   - `ArgState.resetForWorldLoad()` очищает только оперативные данные прошлой сессии, включая RoadNetwork;
   - при успешном чтении `ArgSavedData.applyTo()` восстанавливает данные нового мира;
   - при ошибке чтения повторный сброс препятствует использованию частично импортированных дорог;
   - автосохранение и снимок на `SERVER_STOPPING` выполняются только после подтверждённой загрузки соответствующего сервера, чтобы не затереть исходный SavedData пустыми данными;
   - формат `arg_state.dat`, дорожноe NBT, геометрия и блоки миров **не изменены**.

## Проверки PR #26

- [Actions: road save isolation build, run 38933181767](https://github.com/Anwite/four_old_legends/actions/runs/38933181767) — **success**, Java 25 `clean build` + контроль порядка `reset → applyTo → разрешить сохранение`.
- [Actions: Minecraft 26.3 build, run 38933181646](https://github.com/Anwite/four_old_legends/actions/runs/38933181646) — **success**, независимая сборка.
- Логические защитные проверки не являются подтверждением поведения в живом Minecraft: **две разные одиночные сессии**, недекодируемый SavedData и холодный перезапуск JVM требуют отдельных сценариев с собственными disposable-мирами и отчётами.

## Открытые задачи

- Переход мир A → мир B → мир A в одной JVM; убедиться, что дороги и напряжение не переносятся между мирами.
- Ошибка восстановления сохранения: убедиться в отсутствии перезаписи исходного файла (на **копии**, никогда не на пользовательском мире).
- Историческая семантика `RoadEnd.pos`: формат ключа (4 или 6 полей) не гарантирует совместимость геометрии. **Автоматическую миграцию не реализовывать без проверенного архива и утверждённой схемы.**
- `RoadDirector.growFromRandomEnd` пока может удалить открытый конец после неудачного роста; нужно различить недоступные чанки, временные сбои и окончательно непроходимый рельеф.
- Для обычной генерации правые повороты по-прежнему отключены до появления отдельного `road_corner_right.nbt`.
