## Результат — готовый локальный инструмент

Создан пакет **`Wolfenstein_W09_Private_GitHub_Bridge_Windows_KT18.zip`** (10 706 байт; SHA-256 `dbbff8376697e7b5b8c681817385ac8ea9716929936b2b6cc818d9ada9cf9b85`; ZIP CRC PASS), доступен пользователю в беседе. Внутри:
- `START_W09.cmd` — запуск двойным щелчком, только для Windows;
- `W09_Bridge.ps1` — меню выбора ассета, проверка зависимостей, авторизация через GitHub CLI, загрузка из приватного Release, SHA-256, опциональная загрузка только JSON-индексов в приватную исследовательскую ветку;
- `tools/w09_index_resources.py` — Python stdlib, read-only индексатор ZIP и структурированный парсер MPK/SPK по magic 0x12C / чанкам zlib;
- `README_RU.txt`, `QA_RESULTS_RU.txt` — инструкция для непрограммиста и границы теста.

### Архитектура

1. GitHub CLI (`gh auth login --web`) авторизует **локальный ПК**, отдельно от сохранённой браузерной сессии ChatGPT. Никакие пароли/token в чат не запрашиваются.
2. `gh api repos/Anwite/wolfensteion/releases/tags/spk` получает список имён/размеров/достоверных GitHub заявленных SHA-256. По умолчанию — `empty.zip`; можно выбрать одну/несколько миссий; `ALL` с отдельным явным подтверждением для полной загрузки ~2,37 ГиБ.
3. `gh release download spk --repo Anwite/wolfensteion --pattern NAME --dir _downloads`, повторная загрузка пропускается при совпадении SHA-256 существующего локального файла. **Локально скачанные ZIP никогда не загружаются на GitHub скриптом.**
4. Python валидирует SHA-256 ZIP по Release digest, читает содержимое ZIP, потоково проверяет CRC и читает MPK/SPK, извлекая **только метаданные**: тип ресурса, имя, длину, SHA-256, наличие и формат чанков. Ничего не извлекается на диск и не перепаковывается.
5. Генерирует `_reports/<mission>_summary.json` и несколько шардов `<mission>_resources_NNN.json` размером ~250 КБ каждый. При запросе `UPLOAD` — только JSON, **приватная** ветка `research/w09-spk-release-bridge-2026-10-24`, путь `analysis-data/w09/`. При отказе отчёт остаётся локальным. Не публикует бинарные игровые ресурсы.
