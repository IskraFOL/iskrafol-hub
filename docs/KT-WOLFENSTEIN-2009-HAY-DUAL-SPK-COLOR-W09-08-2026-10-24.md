# Wolfenstein 2009 — W09-КТ08: два SPK, два цвета круглого тюка

**Дата:** 24.10.2026. После полученного полного `farm.zip` в КТ07 обнаружены 512×512 дубликаты `dds:models/props/haybale_rnd_d` в `farm_pak02.spk` и `farm_pak08.spk`. Низкодетальная 32×32 версия в `farm.mpk` из KT05 не проявлялась в игре. Для проверки **приоритета загрузки** подготовлен новый изолированный тест.

## Контролируемая разная окраска
- `farm_pak02.spk`: один DDS `models/props/haybale_rnd_d`, **ярко-фиолетовая раскраска**; остальные **71 из 72** ресурсов побайтово совпадают с присланным SPK. Ресурс 512×512, DXT5, 10 mip, альфа/индексы и размеры сохранены. SHA256 patched `0c9a05812f728e5dc5824dd4b886f6ed6901f711d5aa3c64a36d0b076c338e06`.
- `farm_pak08.spk`: тот же DDS, но **ярко-зелёный**, остальные **80 из 81** ресурсов совпадают с присланным SPK. Размер/формат/альфа сохранены. SHA256 patched `fd16af388a691286fdb83d724cb5305d79028f4a0b50fb20886a4caf101cc5ae`.
- Оба SPK остаются с 3 чанками. Проверены zlib, структура имён/длин, точное количество/ключ изменённого ресурса через независимый parser, ZIP CRC, декодирование DDS в PNG для визуальной проверки, копии оригиналов в ZIP не перезаписывались.
- В отдельном `Wolfenstein_Farm_Hay_Bales_SPK_Priority_KT08.zip` (~17.7 MB) два тестовых SPK + русская инструкция + manifest. Изображение `Wolfenstein_Farm_Hay_Bales_SPK_KT08_Preview.png` демонстрирует исходную, пурпурную и зелёную DDS, это **не игровой кадр**.

## Что даёт тест
Фиолетовый тюк — версия pak02; зелёный — pak08; без изменений — искать другой внешний источник/альтернативную модель. Выбор по цвету — свидетельство о применении конкретного ресурса при конкретном запуске, **не универсальная гарантия общего порядка загрузки всех паков**.
