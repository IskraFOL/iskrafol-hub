## Исправлена подтверждённая несовместимость MC 26.3

В `InteriorFurnitureBlock.java` и `PhotoFrameBlock.java`
удалены `MapCodec` и переопределённый `codec()`.
**Minecraft 26.3 удалил Block codecs.** Это было
предварительно выявлено сравнением с актуальными исходниками
и [официальными заметками Fabric](https://www.fabricmc.net/2026/09/15/263.html).

**Внимание:** исходный Draft PR #74 ещё содержит старый код,
а фикс пока только в объединённом тестовом PR #78.
Перед отдельным последующим merge PR #74 требуется перенести этот
фикс и проверить компиляцию.

## Проверка владельцем

Из GitHub Desktop **Fetch** → выбрать
`test/lik-soviet-interior-combined-2026-10-22`.
В IntelliJ IDEA проверить JDK25, Gradle Sync,
запустить **Fabric Tasks → runClient** обычной зелёной кнопкой,
создать **новый Creative Superflat-мир**, не основной Survival.

1. Проверить четыре новых предмета в Creative-вкладке FOL,
   повороты, коллизию и выпадающие предметы.
2. `/legends interior test` на свободной площадке:
   стол, четыре стула, чашка, фото со скином.
3. `/place template oldlegends:lik_soviet_culture_house_abandoned ~ ~ ~`
   на **другой, большой пустой площадке**.
4. Для `_dream` использовать другое место/мир и сравнить фасады,
   лестницы, освещение, Save/Quit/Load.
5. При первой ошибке Gradle сообщить именно текст первой ошибки,
   без ненужных циклов в терминале.
