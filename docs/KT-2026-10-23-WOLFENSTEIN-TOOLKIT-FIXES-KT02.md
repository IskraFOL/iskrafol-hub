# КТ 02 — Wolfenstein 2009: проверка и защита инструментария

**Дата:** 23.10.2026. Самостоятельное исследовательское направление IskraFOL, параллельно Four Old Legends.

Исходные материалы: пользовательский `Wolfenstein_Toolkit.4.zip` (C#, SPK/MPK Toolkit) и `techckaude.zip` (Python-наработки совместно с Claude). Оригиналы сохранены без изменений.

## Изменения, переданные пользователю как отдельные архивы
- Исправлено деление объекта `bytes` вместо его длины (`raw // b.n`) в экспорте геометрии.
- Исправлена передача выбранного каталога OBJ-экспорта.
- Нормализован регистр расширений ресурсов при упаковке C#.
- Исправлена ссылка на отсутствующую иконку проекта; усилена защита от опасных путей распаковки.
- Повышена скорость поиска предполагаемых боксов HKXS.
- Добавлены защитные проверки при неоднозначности буферов моделей.
- **Небезопасное автоматическое исправление Havok заблокировано**, поскольку MOPP не пересчитывается. Это не следует обозначать как исправление физики.

## Проверено / не проверено
- Синтаксис Python и отдельные тесты на настоящей геометрии `farm` и `caverns`: успешная обратная запись неизменённых буферов (побайтовое совпадение).
- **Не проверено:** компиляция C# на Windows, EXE, графический интерфейс в Windows, запуск/прохождение карты в Wolfenstein 2009.
- Изменения не вносились в публичный тулкит DrZenk; это отдельные рабочие исходники, предназначенные для обсуждения и проверки.

Архивы и подробный отчёт хранятся в ChatGPT Library: `/Wolfenstein 2009/KT02-TOOLKIT-FIXES-2026-10-23.md`, `Wolfenstein_2009_Toolkit_CSharp_Source_Fixes_KT02.zip`, `Wolfenstein_2009_Python_Tools_Fixes_KT02.zip`. Не смешивать с выпуском FOL 1.3.0.
