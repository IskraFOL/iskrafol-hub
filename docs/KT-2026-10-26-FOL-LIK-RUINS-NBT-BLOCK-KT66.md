# КТ66 — Four Old Legends: намеренный запрет руин Лика до утверждённой NBT

Дата: 26 октября 2026. Уточнение от пользователя: совместно с Claude принципиально решено НЕ разрешать генерацию руин, поскольку отсутствует необходимая одобренная NBT-постройка.

## Исправлено после неверной интерпретации в КТ62–КТ65

В прежнем коде событие likRuins ошибочно оставалось доступно при высоком напряжении и через ручную команду: вместо постройки вызывались tracks и выдавалось достижение lik_ruins_found. Это противоречило согласованному ограничению. Ошибка предыдущих КТ признана и исправлена.

Код: [FOL Draft PR #106](https://github.com/Anwite/four_old_legends/pull/106), отдельная ветка от PR #105.

- Удалена регистрация руин из случайного пула Лика; удалён псевдообработчик likRuins, ручной вызов не запускает следы/ложное достижение.
- Команда /legends build ruins / руины теперь отвечает отказом с локализованным сообщением об отсутствии утверждённой NBT.
- Оставлены все семь будущих сюжетных условий финала LikChronicler: снижение до шести без согласования запрещено. Пока руин нет, честный финал новым игровым прохождением недоступен.
- Старые сохранённые достижения не удаляли. Существующая модераторская команда chronicler unlockall — отдельный отладочный обход для теста финала, не генерация руин.
- Регрессионные скрипты КТ62 и КТ65 исправлены, добавлен check_lik_ruins_disabled_kt66.py.

## Проверки

PASS: 12/12 структурных проверок исходников, 14/14 модельных сценариев (7 уровней напряжения × allowGriefing ON/OFF). 27 активных записей Лика и 19 пороговых событий. NOT RUN: реальные Python-скрипты в полном клоне, Java25/Gradle/Minecraft. Не выдавать модель за игровой тест.

## Обязательное правило

Руины не генерировать, не создавать и не добавлять NBT без отдельного задания и разрешения пользователя. После готовности NBT требуется безопасная установка, игровое тестирование, подтверждение достижения по реальному успеху. Сохранить правило Release First.
