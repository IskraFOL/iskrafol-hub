# Four Old Legends — утверждённая центральная архитектура мира и сна Лика

Дата утверждения владельцем: **22 октября 2026 года**.
**Долгосрочное утверждённое направление** Four Old Legends, не
подтверждение полной реализации в релизе.

## Главный принцип: «осколки Северного» ↔ «Северный целиком»

**Обычный Overworld:** игрок по мере роста ARG-напряжения встречает
отдельные фрагменты Северного. Сюжетные постройки Лика возникают по
событиям относительно близко к игроку, но только после выполнения
условий, с шансом и глобальными кулдаунами — **не обязательно сразу
при достижении числового порога**. Развивающаяся сеть дорог и
обычная советская застройка должны дополнять картину
**процедурно**, с сохранением чужих построек, лута и BlockEntity.
Облик заброшенный: пустые дома, разрушения, тишина, сорняки,
пыль, затихшая городская инфраструктура.

**Сон Лика:** постепенно открывающийся игроку **один единый
Северный с фиксированной узнаваемой планировкой**, в котором
отдельные находки обычного мира соединяются в улицы, районы и
сюжетные места. Те же формы зданий и помещения, но со светом,
голосами, деятельностью обитателей, целыми фасадами и бытовыми
деталями. Руины во сне показывают район до разрушения.
Идея не означает, что NPC или сон уже реализованы кодом.

**Не подменять основной Overworld во сне:** предпочтительна
безопасная самостоятельная локация (отдельное измерение либо
изолированная сцена после техаудита); возвращение после пробуждения
без изменения пользовательских сохранений. Сначала аудит DreamDirector,
затем согласование механизма изоляции. Сейчас DreamDirector — в
основном короткие видения; `dreamsEnabled=false` по умолчанию.

## Утверждённый визуальный масштаб: «как на концепт-артах»

Владелец требует крупных, впечатляющих, проходимых снаружи и изнутри
зданий, узнаваемых по утверждённым игровым визуализациям:
- промышленная наблюдательная вышка Лика;
- большой советский Дом культуры с актовым залом;
- разрушенный участок панельного жилого квартала;
- двухэтажный коммунальный жилой дом.

Ориентир всей стилистики —
`soviet_panel_5story.nbt` из отдельной ветки ASSET-01, размер
**43×23×17**. В самой игре проверка масштаба ещё ожидается.
Правило Minecraft Structure Block: до 48 блоков по оси;
город должен складываться из **нескольких больших NBT**, а не
одной невозможной по габаритам структуры.

**Исключения:** архив и склеп не перестраивать.
В коде до идентификации архива консервативно защищены
`likLibrary`, `likVault`, `lik_library.nbt` и безусловно
`crypt.nbt`. Книги, голосовые записи, достижения, пороги
напряжения и сюжетные сцены сохранять.

## Реальный прогресс NBT — 22 октября 2026

[Four Old Legends Draft PR #76](https://github.com/Anwite/four_old_legends/pull/76),
ветка `feature/lik-soviet-large-nbt-dual-state-2026-10-22`,
base: [дизайн Draft PR #75](https://github.com/Anwite/four_old_legends/pull/75).

**Восемь готовых двоичных GZIP NBT**:
| Здание | Габариты (X×Y×Z) | Состояния |
| --- | --- | --- |
| Техническая вышка | 19×43×19 | abandoned + dream |
| Дом культуры | 47×21×37 | abandoned + dream |
| Панельные руины | 47×23×36 | abandoned + dream |
| Коммунальный дом | 45×17×23 | abandoned + dream |

Исходник `scripts/generate_lik_soviet_nbt.js` воспроизводит все
8 файлов; `scripts/check_lik_soviet_nbt.py` должен проверить их
независимо. Загруженные в GitHub бинарные файлы прошли **8/8
контроль CRC32/GZIP и 8/8 полную проверку дерева NBT** внешним
проверяющим JS-кодом. Парные координаты совпадают на
99,6%, 99,2%, 88,9%, 99,2% соответственно.

Подготовлен, но **не исполняется движком**:
`docs/LIK-NORTHERN-DREAM-DISTRICT-2026-10-22.json` с
позициями четырёх объектов и каркасом уличных осей.

**НЕТ ещё:** JDK25 Minecraft 26.3 теста, подтверждения визуальной
внешности, автоматического появления в Overworld, сохранённого
сюжетного содержимого в новых шаблонах, единого измерения сна,
NPC/звуков/взаимодействий, полноценной генерации города.
До реального игрового осмотра ассеты не считаются финальной моделью.

## Протокол принятия

1. Сначала проверить новые NBT в отдельном Creative Superflat-мире
   через IntelliJ Play, **не** на основном сохранении.
2. Проверить масштаб и проходимость каждого здания, сделать
   одинаковые кадры обеих версий, согласовать доработки.
3. Вернуть текущие книги/пюпитры, достижения и сундуки из
   существующих алгоритмов Лика, привязать события **только
   после проверки placement/preflight**.
4. Отдельно развивать безопасную локацию сна и алгоритм сборки
   Северного, не перезаписывая Overworld игрока.
5. Добавить серверные/клиентские GameTest после подтверждения
   самого тестового контура PR #73 на Java 25/Fabric 26.3.
6. Не запускать GitHub Actions без отдельного разрешения,
   не сливать Draft PR без приёмки владельца.
7. Новые комментарии Java — на русском; правило Release First:
   очередность релизов сохраняется, новая система не блокирует
   уже замороженные функции.

**Эта запись закрепляет подтверждённое пользователем решение
для последующих разговоров и работ IskraFOL.**
 

## Уточнение публичного наименования и фирменных публикаций — 22.10.2026

**Новое прямое решение владельца, имеет приоритет над ранними формулировками этого документа:**

- В **публичных материалах Minecraft-мода Four Old Legends** не использовать
  имя «Северный». Это рабочее название мира/карты и другой сюжетной
  разработки, не название города, раскрываемое игрокам в Minecraft.
- По умолчанию **вообще не называть город** в постах, описаниях и
  анонсах — сохранять загадку.
- Если без обозначения никак, допустимо **«Город-Призрак»** (англ.
  `Ghost Town`), без собственного топонима. Не объявлять это
  отдельным утверждённым каноническим именем.
- В старых документах архитектуры слово «Северный» может оставаться как
  историческое/внутреннее обозначение технического макета; оно **не
  является разрешением** использовать его в публичной коммуникации
  Four Old Legends или включать в новые сюжетные реплики.
- Фирменный стиль Telegram: короткие атмосферные двуязычные фразы
  **EN → сразу RU**, эмодзи-заголовок, горизонтальные разделители
  `---`, финальная подпись
  **«Four Old Legends — They're all alive... / Они все живы...»**.
  Не разбивать весь пост на два громоздких языковых блока.
- Boosty — авторский дневник BrainMystycal, допускает больше
  закулисного контекста, но сохраняет такую же языковую и
  стилистическую идентичность. Не обещать дату релиза непроверенных
  функций и не объявлять юбилейные цифры достигнутыми до подтверждения.
