## Расширение: языки, темы, обратная связь

По запросу пользователя добавлены полные RU/EN и переключение тёмной/светлой темы с сохранением выбора. Палитра опирается на иконку самого мода: тёмный фон, бирюзовый, фиолетовый, красный и белый. Исходная иконка включена в шапку и favicon.

Социальные ссылки: https://t.me/four_old_legends и https://boosty.to/brain_mystycal (актуальная ссылка с подчёркиванием, подтверждённая пользователем и описанием Modrinth).

Пользователь выбрал отправку прямо с сайта через FormSubmit. Получатель — `Anwite@yandex.ru`. Форма настроена с нативным POST, обязательными полями, проверкой email, ограничением сообщения и CAPTCHA. Для включения приёма владелец должен отправить форму один раз и подтвердить email по письму FormSubmit. Активация и реальная доставка пока не подтверждены; автоматическое письмо не отправлялось.

Подтверждены production-сборка, рендер RU/EN с проверкой перевода/ID/соцссылок/формы и работа первоначального рендера при недоступном localStorage. Браузерные проверки остаются открытыми. Новая публикация Sites получила статус `succeeded`.

## Исправление формы по скриншоту пользователя

При попытке отправки во встроенном просмотре ChatGPT показан ERR_BLOCKED_BY_CSP для FormSubmit. Исправлена форма: POST открывается в отдельной вкладке, введённый текст сохраняется на странице, добавлены инструкции RU/EN и повторное открытие. Успех не объявляется по нажатию кнопки. Production-сборка и локальные проверки рендера обеих локализаций пройдены. Sites подтвердил публикацию со статусом succeeded. Реальная доставка и подтверждение почты всё ещё требуют пользовательской проверки.
