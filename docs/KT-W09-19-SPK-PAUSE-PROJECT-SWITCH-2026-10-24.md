## Завершённый этап исследования Wolfenstein 2009

- **Ресурсы:** 15 архивов ZIP в PRIVATE GitHub Release `Anwite/wolfensteion`, tag `spk`; метаданные, размеры и GitHub SHA-256 доступны. Скачивание самих бинарных вложений через доступный GitHub connector не подтверждено.
- **Браузер:** авторизация в GitHub настроена; страница приватного релиза и ссылка на `empty.zip` открываются; браузерная автоматизация не возвращает байты скачанного файла.
- **GitHub Actions:** тестовый workflow на отдельной ветке `research/w09-spk-release-bridge-2026-10-24` не стартовал из-за предупреждения GitHub о платежах или лимите расходов. Автозапуск на push отключён; повторно не запускать без изменения условий.
- **Локальный мост:** пакет `Wolfenstein_W09_Private_GitHub_Bridge_Windows_KT18.zip` содержит `START_W09.cmd`, PowerShell и Python-анализатор, загрузку Release через GitHub CLI и opt-in публикацию **только JSON-индексов** в приватную исследовательскую ветку. На ранее предоставленных `global.zip` и `farm.zip` статическая проверка успешно прочла 979 и 6294 ресурсов соответственно; **Windows запуск, GitHub CLI скачивание и публикация JSON на компьютере пользователя ещё не протестированы**.
- **Задача при возобновлении:** провести smoke test `START_W09.cmd` сначала на `empty.zip`, проверить SHA-256/ZIP CRC, затем (только при явном `UPLOAD`) прочесть индексы из приватной ветки. Не запрашивать заново те же файлы и не путать результат метаданных с бинарным аудитом.
