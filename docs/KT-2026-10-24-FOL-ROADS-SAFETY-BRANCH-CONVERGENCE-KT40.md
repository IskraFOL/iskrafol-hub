# КТ 40 — FOL 1.3.0: безопасность дорог и расхождение веток
Дата: 24.10.2026. Тип: статический аудит (без изменений игрового кода).

## Главный вывод
**Draft PR #86 не содержит уже подготовленные P0- и P1-защиты из альтернативной цепочки Draft PR #70 → #72.** Развитие ветки #86 без сверки с #72 рискует исключить ранее написанную безопасность из FOL 1.3.0.

По исходникам (Structures.java, RoadBuilder.java, RoadDirector.java) статически сопоставлено **10/10 контрольных различий**: защита NBT-следа, снимок и откат, удаление опасного прохода по чужим маркерам, корректная обработка фонарей и остановка удаления концов дорог. Это **не Minecraft PASS**.

## Границы защиты
- В #86 автоматический рост по-прежнему может заменить твёрдые блоки на ровном участке: `keepNeighbours=true` защищает лишь от воздуха в NBT.
- В #72 существуют `RoadPlacementSafety.preflight/snapshot/rollback`, `RoadTerrain.analyze` и повторные проверки; код существенно безопаснее.
- **Остаточный риск #72:** `RoadTerrain.canGrade` допускает обычный природный камень/грунт, который не отличить от установленного игроком лишь по BlockState. Абсолютная защита не доказана.
- Другой Draft PR #57 и последующие #58–#61 уже включают физическую автобусную остановку; отсутствие её коллизий в ветке #86 не означает, что она вообще не реализована.
- Полная сборка JDK25, Minecraft 26.3 и игровая приёмка **NOT RUN**; критический пункт интеграции остаётся открытым.
