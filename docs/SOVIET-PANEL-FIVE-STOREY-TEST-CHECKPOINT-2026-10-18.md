# КТ 18.10.2026 — советская панельная пятиэтажка: пакет для игрового теста

**Решение владельца:** «Предлагаю зафиксировать тест панели КТ»; сделать контрольную точку и остановить текущий этап на проверке модели, без выдачи непроверенной постройки за принятую.

## Что создано

По одобренному владельцем ТЗ создана **авторская Minecraft Structure NBT**: советская панельная пятиэтажка по мотивам серии 1-464, **двухподъездная, 5 этажей, 40 квартир**, доступные подъезды, лестницы, балконы, двери, комнатные перегородки и базовая мебель. Главный приоритет — реалистичные фасад и планировка, детализация в духе ранее принятой автобусной остановки, без выдачи игровой модели за точную копию строительных чертежей.

**Файлы, созданные в текущем рабочем пространстве и доступные пользователю в беседе:**
- `soviet_panel_five_storey_26_3.nbt` — настоящий бинарный gzip-NBT, **43 980 байт**.
- `soviet_panel_five_storey_README.md` — инструкция по загрузке через Structure Block, вопросы безопасности.
- `soviet_panel_five_storey_26_3_package.zip` — NBT + README + исходный генератор `generate_soviet_5floor.py` (в ZIP). Рабочая копия передана пользователю в беседе; **не утверждать, что бинарный NBT уже загружен в GitHub**.

**Номинальные параметры:** 42 × 23 × 23 блоков (X × Y × Z); `DataVersion=5023`, палитра NBT c `id` / `properties`; 16 298 записей блоков, 38 состояний палитры, 40 входов в квартиры, 32 балконные двери, 40 кроватей, 8 межэтажных лестничных переходов (по данным статической проверки, не игровые свидетельства).

## Что подтверждено

- 18.10.2026 файл существует в рабочем контейнере, имеет формат gzip; успешная декомпрессия NBT до 589 422 байт.
- ZIP архив читается, `ZipFile.testzip()` не находит повреждений; в пакете три названных файла.
- Ранее выполнена программная проверка размера, целостности NBT, ссылок на палитру, блоков и пар дверных частей. **Это не заменяет загрузку в реальном Minecraft.**

## Что НЕ проверено

- Реальная загрузка Structure Block в **Minecraft Java 26.3**.
- Корректное отображение фасадных панелей, окон и балконов, проходов через двери, доступность всех этажей и лестниц, размеры внутренних помещений и отсутствие коллизий.
- Реакция на поворот здания, освещение, производительность, пригодность для автоматической генерации.
- Конкретных игровых скриншотов/видео именно пятиэтажки от владельца пока нет; **это КТ подготовки к тесту, а не успешной игровой приёмки**.

## Как провести проверку (без терминала и GitHub Actions)

1. Использовать **копию тестового мира** с включёнными командами. Не размещать поверх строений, дорог и остановки.
2. Поместить `soviet_panel_five_storey_26_3.nbt` в папку сохранения мира `generated/minecraft/structures/`.
3. Дать себе `/give @s minecraft:structure_block`, открыть интерфейс **LOAD**, указать имя `minecraft:soviet_panel_five_storey_26_3` и загрузить структуру по инструкции из README. При изменениях интерфейса 26.3 остановить тест, сообщить экран, а не ломать действующее сохранение.
4. Пройти фасад/оба подъезда/лестницы/квартиры/балконы, сделать несколько скриншотов. На следующем этапе по ним исправлять геометрию.
5. **Не интегрировать** NBT в автоматическую генерацию Four Old Legends без дополнительного согласования: размер большой, шаблон может заменить блоки в существующем мире.
