# IskraFOL — утверждённая возможность автоматического тестирования Minecraft

**Статус:** утверждено владельцем 22.10.2026, долгосрочная техническая возможность,
обязательная для дальнейшей дорожной карты тестирования проектов Minecraft.
Зафиксировано по прямой просьбе владельца: **не забывать** о возможности
автоматических проверок после смены чата или этапа разработки.

## Постоянное решение

Автоматизированная проверка Minecraft-модов **возможна без виртуальной
машины** посредством **Fabric Server GameTest** на реальной логике Minecraft
(выделенный тестовый сервер) и, отдельно, **Fabric Client GameTest** для
настоящего рендера/интерфейсов. Тестирование можно запускать локально через
IntelliJ/Gradle; при доступной физической машине возможно расширение до
self-hosted runner. Xvfb — дополнительный виртуальный **дисплей**, не VM.

Это техническая **возможность** и реализованный пилот, не утверждение о
работающих без ошибок автотестах.

## Жёсткие границы

1. **Никогда не заявлять PASS по существованию тестового метода.** Разделять
   `STATIC`, `COMPILE`, `SERVER_RUNTIME`, `CLIENT_RUNTIME`.
2. Реальные файлы `saves` пользователя не трогать; отдельный тестовый мир.
3. EULA не принимать молча — по умолчанию `false`; согласие владельца
   только после прочтения лицензии.
4. GitHub Actions на аккаунте с исчерпанными минутами не запускать без
   отдельного разрешения; self-hosted требует включённого компьютера.
5. Не сливать Draft PR без явного разрешения владельца и его приёмки.
6. Не заменять проверку визуала серверными тестами — диктофон, UI, звук,
   полное отображение остановки требуют клиента.
7. Известная текущая среда FOL: Minecraft 26.3 / JDK 25 /
   Fabric Loader 0.19.5 / Loom 1.17.18 / Fabric API 0.161.0+26.3.
   Совместимость тестового source set и API должна быть подтверждена
   компиляцией, несмотря на существование официальной документации.
