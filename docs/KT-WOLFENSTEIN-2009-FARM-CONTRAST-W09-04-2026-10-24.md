# Wolfenstein 2009 — W09-КТ04: повторная игра без краша; контрастный тест текстуры

**Дата:** 24.10.2026. **Проект:** Wolfenstein 2009 на оригинальном движке, отдельно от Four Old Legends.

## Результат предыдущего теста пользователя

После установки экспериментального `farm.mpk` из W09-КТ03 (замена одного DXT1 `textures/ground/path_farm_d` на оранжевый) пользователь сообщил: **игра загрузилась без вылета и крашей; оранжевую дорожку обнаружить не удалось.** Это положительный smoke-PASS по загрузке второго изменённого контейнера, **не подтверждение отображения изменённой текстуры**.

Возможные причины невидимости: конкретная текстура находится в другой части уровня, применена неочевидно/смешивается материалами, перекрывается альтернативными ресурсами (SPK/MPK), путь иной; отладка нужна без предположения, что изменение обязательно должно быть видно.

## Новый контролируемый эксперимент КТ04

Создан `Wolfenstein_2009_Farm_Purple_Lime_Checker_KT04.zip`. Основа: *ранее прошедший загрузку* no-change `farm.mpk` КТ02; **не поверх КТ03**.

Изменён ровно **один** ресурс: `dds:textures/ground/path_farm_d`; яркий контрастный фиолетово-салатовый шахматный узор на уровне сжатых DXT1 4×4 пиксельных блоков. DDS сохраняет **32×32, DXT1, 6 mip-уровней, 87 DXT1-блоков**, исходные индексы пикселей, режим кодирования прозрачности и размер. Остальные **2 044 ресурса** бинарно неизменны при распаковке MPK.

Реальная программная проверка: внутренний ZIP CRC/структура PASS; MPK magic/chunk zlib/названия/размеры ресурса/SHA256 сравнение через независимо написанный Python parser PASS; число ресурсов **2 045**, чанков MPK **48**, модифицирован **1**, отсутствуют удалённые/добавленные записи, форматы/типы остальных ресурсов неизменны. SHA256 изменённого MPK: `80b8553fe85c0ccd48a957946c15e4085167c6a893abeedc31ab2e1fddd975f0`.

Дополнительное чтение ресурсов no-change контейнера выявило несколько ссылок на `path_farm` в `maps/game/farm/farm` и моделях `crystal_farm`, но **точное видимое место текстуры не идентифицировано**.

**Этот новый КТ04 MPK пока НЕ проходил пользовательский игровой тест.** Возможность загрузить изменённый ресурс и увидеть новый материал остаётся разными критериями.

## Ближайший пользовательский тест

1. Сделать резервную копию рабочей `farm.mpk`. Игру закрыть.
2. В **отдельной тестовой копии** игры заменить лишь `farm.mpk` на файл из папки `test_copy` нового ZIP. `farm_pak01.spk`, `farm@tpd.spk`, Havok, карты, остальные архивы не менять.
3. Загрузить «Ферму»; отметить PASS/FAIL входа, яркую фиолетово-салатовую текстуру на дорожке/почве возле поселений или двора, сделать скриншот.
4. Если изменений опять не видно — **прекратить подбор оттенков**. Следующий этап: исследовать, какой материал использует данную текстуру и откуда загружает ресурс игра; выбрать гарантированно видимый объект для третьего эксперимента.
5. Вернуть успешно загружавшийся no-change файл после теста.
