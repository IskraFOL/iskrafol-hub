# КТ60 — Four Old Legends: экспериментальное заглубление новых плоских дорог

**Дата:** 26.10.2026. Статус: **эксперимент, не для main и не для игровых сохранений**.

После [КТ59 / FOL Draft PR #99](https://github.com/Anwite/four_old_legends/pull/99) создан отдельный [FOL Draft PR #100](https://github.com/Anwite/four_old_legends/pull/100), ветка `experiment/road-flush-seed-2026-10-26`, исключительно для проверки предложенной пользователем высоты «-1» дорожного полотна.

### Что реально изменено

- Новый `seedSomewhere()` берёт `groundOf(...).below()`: дорожный блок занимает место естественного верхнего грунта, не висит над ним.
- В `footprintOk()` базовая поверхность сравнивается через `at.getY()+1`, не меняя допуск ±2 и запрет воды.
- Ручные `straight/corner_left/corner_right` используют такую же начальную отметку; отдельный NBT-стенд `/legends road test` намеренно оставлен без вертикального сдвига.
- **Не менялись:** `RoadBuilder.groundOf()` (сохраняет исходную семантику Heightmap и береговых тестов), `entryFrom(RoadEnd)`, позиции уже созданных дорог, мосты, лестницы, склоны, серпантины и их SavedData.

### Проверки

- **PASS: 13 статических инвариантов**, перепроверено чтением актуальных Java и нового теста из ветки GitHub.
- **PASS: 32 расчётных случая** — 4 высоты поверхности × 4 направления × перепад ±1. При верхнем природном блоке Y=63 получаем дорожный блок Y=63 и одинаковую физическую высоту верха 64.
- **NOT RUN:** реальная Python проверка в полном checkout; JDK25 и Gradle; Minecraft 26.3; мост через воду; естественный рельеф; продолжение старой сети; Save/Quit/reopen. Не объявлять функцию готовой для 1.3.0.

### Следующее решение по Release First

Сначала провести игровой PASS КТ58/КТ59. После — отдельно протестировать `/legends road` в новом одноразовом мире из ветки PR #100. Для реального включения в релиз потребуется проверить стыковку новых заглублённых дорог с мостами и горными соединителями, а также полную сохранность старого `RoadEnd`; при возможном пороге на стыке эксперимент не сливать.

**Важно:** никто не изменял `main`, не сливал ветки, не запускал GitHub Actions и не менял существующие миры. Никаких автоматических или фоновых работ не обещано.
