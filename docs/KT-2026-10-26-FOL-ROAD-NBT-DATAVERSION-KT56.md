# КТ 56 — Four Old Legends 1.3.0: восстановлена правильная NBT-палитра для MC 26.3

**Дата:** 26 октября 2026 г.  
**Стадия:** код/ресурсы подготовлены, бинарная и геометрическая проверка PASS; Minecraft/JDK25/Gradle **ещё не запускались**.

## Причина проверки

В КТ51 пользователь подтвердил ошибку `EMPTY_NBT_FOOTPRINT` у дорожного поворота после первого прямого сегмента. В КТ54 добавлена ранняя NBT-проверка до изменения мира. В КТ55 подключён отдельный зеркальный правый поворот, но повторилась ошибка палитры из КТ38.

## Найдено по официальному changelog Minecraft Java 26.3

Mojang изменила Block State NBT поля с `Name/Properties` на **`id/properties`**. Это относится к DataVersion **5023**. Таким образом:
- старые прямой и мост (**4790**) с `Name/Properties` корректны;
- оба угла (**5023**) должны использовать `id/properties`;
- переименование ключей у левого угла в КТ38 и правого в КТ55 было ошибочным, несмотря на PASS статической проверки, которая повторяла неверное предположение.

Официальный источник: https://www.minecraft.net/en-us/article/minecraft-java-edition-26-3

Это хорошо объясняет случай `EMPTY_NBT_FOOTPRINT`, однако причинность должна быть подтверждена новым запуском Minecraft.
