# КТ 55 — Four Old Legends 1.3.0: правый зеркальный поворот интегрирован

Дата: **26 октября 2026**. Статус: **реализовано в отдельной ветке; игровой тест ещё не пройден**.

## Почему потребовалась КТ

После объединения аудита в PR #93 правый ресурс `road_corner_right.nbt` уже находился в игре, но `RoadBuilder.ALLOW_RIGHT_TURNS=false`. `RoadDirector` и `RoadGeom` всё ещё воспроизводили правый поворот обратным проходом левого шаблона. Файл зеркального правого угла, созданный 17 октября, содержал старую палитру `id/properties`, тогда как после КТ38 Java Edition 26.3 использует `Name/Properties`.

## Реальная работа в GitHub

**Draft PR:** [Four Old Legends #97](https://github.com/Anwite/four_old_legends/pull/97).  
**Ветка:** `feature/road-right-corner-integration-2026-10-26`.  
**База:** `fix/road-bench-nbt-preflight-2026-10-25` (КТ54, PR #96), без изменения `main`.

1. В настоящем бинарном `road_corner_right.nbt` исправлены **18 строковых NBT-тегов `id`→`Name` и 14 compound-тегов `properties`→`Properties`**. Сохранены геометрия, индексы, `DataVersion=5023` и все координаты.
2. В `RoadBuilder` установлен `ALLOW_RIGHT_TURNS=true` и добавлен `CORNER_RIGHT_STRUCTURE`; выбор кандидата по-прежнему проходит проверки участка и шаблона.
3. В `RoadGeom` восстановлены точки зеркального поворота из исходного ROAD-01 (вход X=7..12, Z=1; выход X=0,Z=11), а также `markCornerRight`.
4. В `RoadDirector` новые точки используются для автоматического роста, ручного `corner_right`, предпроверки и снимка семисегментного стенда. Логика безопасного отката не отменена.
5. `Structures` и `RoadTerrain` распознают самостоятельный правый NBT с правильным полотном. Обновлены статические Python-тесты и скрипт зеркалирования, чтобы не возвращать устаревшую NBT-палитру.

## Доказательства проверки

- **PASS:** исходный и новый GZIP декодированы без ошибки; у нового файла CRC32/ISIZE совпадают с данными NBT.
- **PASS:** полная структура NBT успешно прочитана из GitHub: `DataVersion=5023`, размер 13×8×17, **1767 уникальных блоков**, 18 состояний с `Name`; индексы и координаты корректны, отсутствуют старые `id/properties` в палитре.
- **PASS:** 16 рядов ожидаемого полотна Y=0 (X=7..12 вход, X=0..12 поперечный рукав) без расхождений.
- **PASS:** 15 read-only статических инвариантов связей Java и Python.
- **Не выдаём старые тесты за новые:** исторический PR #54 ранее подтвердил Minecraft 26.3, 7 сегментов/6 стыков, 10/10 контрольных блоков. Новый код КТ55 в игре не проверялся.
