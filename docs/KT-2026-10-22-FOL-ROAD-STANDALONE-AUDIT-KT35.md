## Фактический результат
1. Тест `scripts/check_road_nbt_geometry.py` ранее требовал отсутствующий как проектную зависимость пакет `nbtlib`.
2. `scripts/check_road_bench_seams.py` требовал отсутствующий заранее сформированный файл `road-nbt-report.json`, а при любом запуске сохранял временный JSON в корне.
3. Новый `scripts/road_nbt_reader.py` использует только стандартный Python, читает структуру непосредственно из `data/oldlegends/structure/*.nbt` и проверяет GZIP, названия тегов `Name`, координаты, индексы палитры и дубли.
4. Оба теста переподключены к реальному источнику NBT. Старый JSON-аргумент теста стыков сохранён для совместимости, выходной отчёт записывается только с `--report`.
5. Исправлен устаревший комментарий в `RoadBuilder.java`: размер угла 13×17 вместо 15×17. Рабочие NBT, Java-алгоритм дорожной сети, `main` не менялись.

### Результаты с честной маркировкой
- **PASS 8/8:** анализ структуры исходных текстов тестов, импортов и обработчиков.
- **PASS 144/144:** независимая математическая сверка обратимости 2D-координат для четырёх направлений и трёх габаритов.
- **NOT RUN:** реальный запуск Python на дорожных NBT, проверка 6 стыков для четырёх направлений; JDK25/Gradle/Minecraft 26.3/игровой обход.

## Нерешённые проблемы прежнего аудита
- `ALLOW_RIGHT_TURNS=false` — правый поворот ещё не подключён и не принят.
- У моста высотные уровни настила; footprint проверка на одном Y не подтверждает проходимость.
- Лестничные соединители, крутые склоны, водные мосты и автогенерация требуют отдельной реализации/геймплейных тестов.
- **Release First:** сначала верификация и исправления для релиза 1.3.0, без добавления новых функций.
