# W09-КТ17 — приватный мост GitHub Releases → Actions → анализ SPK

**Дата:** 24 октября 2026 года. **Проект:** Wolfenstein 2009, моддинг оригинального движка.

## Решение пользователя

Проверить получение бинарных MPK/SPK из **приватного** GitHub Release `Anwite/wolfensteion` → tag `spk` без повторной передачи ZIP в ChatGPT. После успешной браузерной авторизации пользователь одобрил эксперимент с GitHub Actions.

## Реально выполнено

1. Проверено API: у `Anwite/wolfensteion` есть `main`, репозиторий **Private**, до эксперимента не было workflow runs.
2. Создана **изолированная ветка** `research/w09-spk-release-bridge-2026-10-24` от main. **Никаких изменений в main**.
3. В ветку добавлен `tools/w09_verify_release_zip.py` (commit `51f316d9228988fede91a841e37d76e270a31a4c`). Скрипт только читает файл, проверяет ожидаемую контрольную сумму ZIP и CRC каждого вложенного элемента, перечисляет записи, вычисляет SHA-256 вложенных файлов и формирует `report/empty_zip_manifest.json`. Содержимое архива не извлекает на диск, изменяемые игровые файлы отсутствуют.
4. Добавлен workflow `.github/workflows/w09-private-spk-bridge.yml` (commit `0059f7fc444fd927b5b2606c27219bc9b60fe673`) с `on: push` только для изолированной ветки и ручным `workflow_dispatch`; `permissions: contents: read`. В Ubuntu-runner предусмотрено `gh release download spk --pattern empty.zip`; затем Python-проверка и загрузка **только метаданных** в Private Actions artifact с retention=1 день.
5. GitHub инициировал [run #40123933939](https://github.com/Anwite/wolfensteion/actions/runs/40123933939): **completed / failure** за одну секунду, job id `120961207540`, нет исполненных steps, `runner_id=0`, логи не были созданы. Это **не ошибка SHA/ZIP/SPK и не ошибка выполнения Python** — workflow не получил runner.
6. Через авторизованный браузер подтверждена точная GitHub-аннотация:
   > The job was not started because recent account payments have failed or your spending limit needs to be increased. Please check the 'Billing & plans' section in your settings.
   Это **две альтернативы**, точный тип ограничения аккаунта не установлен. Ранее пользователь уже сообщал об исчерпании 100% бесплатных минут GitHub Actions у Anwite.
7. **Никакие ZIP из релиза не скачаны исполняющим runner'ом**, проверка SHA-256 и CRC файла `empty.zip` **не состоялась**. Уже прочитанные метаданные private Release и SHA-256 с сайта остаются в W09-КТ16. В репозиторий не загружались коммерческие игровые ресурсы.

## Статус и дальнейший путь

- Браузерный вход в GitHub подтверждён (профиль пользователя), открытие приватного Release и ссылка на `empty.zip` доступны. Браузерная автоматизация не передаёт байты скачанного ZIP для локальной обработки.
- **Мост создан и готов для повторного запуска при доступности GitHub Actions, но пока НЕ работает из-за блокировки биллинга.** Не обещать, что получение private Actions artifact даст сразу локальную файловую систему: это отдельная предстоящая проверка.
- Не предлагать платную подписку/изменение лимита расходов как обязательный шаг. Возможные пути: дождаться восстановления лимита; исследовать альтернативный авторизованный канал получения бинарных данных; пока продолжить изучение ранее предоставленных `Farm`, `Caverns`, `Global` и `brains.rar`.
- Музыка Four Old Legends «Кто-то помнит» v0.3 остаётся на паузе; релиз FOL 1.3.0 не ускорять.
- GitHub Actions не перезапускать без изменения обстоятельств, **никаких слияний в main без разрешения пользователя**.
