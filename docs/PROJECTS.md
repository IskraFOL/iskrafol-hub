# Реестр проектов IskraFOL

**Последнее обновление:** 13 октября 2026 года  
**Назначение:** единая точка входа для отслеживания проектов экосистемы IskraFOL, их состояния, ближайших целей и незавершённых задач.

## 1. Центральный хаб

### IskraFOL Hub
- **Репозиторий:** https://github.com/IskraFOL/iskrafol-hub
- **Видимость:** публичный
- **Роль:** центральная карта проектов и документация экосистемы.
- **Текущее состояние:** проведён первичный аудит; интеграция GitHub проверена тестовой записью.
- **Следующая цель:** опубликовать реестр проектов, согласовать единый формат карточек и определить правила обновления статусов.

## 2. Активные проекты

### FOL Engine
- **Репозиторий:** https://github.com/Anwite/FOL-Engine
- **Видимость:** приватный
- **Назначение:** собственный игровой движок FOL Engine.
- **Текущее состояние:** в удалённом репозитории присутствуют базовая структура движка, CMake-конфигурация, игровые и движковые каталоги. Ранее была подтверждена успешная сборка и работа системы времени.
- **Ближайшая цель:** продолжить развитие ядра и проверить текущие изменения Logger: временные метки, запись журнала в файл, единый формат ошибок и корректное завершение работы.
- **Что ещё проверить:** актуальное состояние локальной рабочей копии и соответствие последних изменений удалённому репозиторию.

### Four Old Legends — Minecraft Mod
- **Репозиторий:** https://github.com/Anwite/four_old_legends
- **Видимость:** приватный
- **Назначение:** Minecraft-мод о четырёх легендах — Herobrine, NULL, Entity 303 и Лик.
- **Текущее состояние:** открыт PR № 1 с исправлениями конфигурации, синхронизации настроек, диктофона и очистки временных состояний.
- **Ближайшая цель:** проверить изменения PR, включая сценарии перехода между мирами и остановки игры.
- **Ограничение:** многопользовательская синхронизация требует отдельной проверки. Не сливать PR без подтверждения владельца проекта.

### Four Old Legends — Website
- **Репозиторий:** https://github.com/Anwite/four-old-legends-website
- **Видимость:** приватный
- **Назначение:** официальный сайт проекта Four Old Legends.
- **Текущее состояние:** открыты два связанных PR: базовая настройка React, TypeScript и Vite, а также улучшение атмосферного дизайна главной страницы.
- **Ближайшая цель:** проверить сборку и запуск сайта локально, оценить адаптивность, доступность и готовность временных изображений к замене.
- **Ограничение:** PR № 2 основан на ветке PR № 1. Сохранять эту зависимость; не сливать изменения без подтверждения владельца проекта.

## 3. Проекты в планировании

### «Обратной дороги нет»
- **Назначение:** самостоятельная сюжетная игра с атмосферой тайны и постепенным раскрытием событий.
- **Текущее состояние:** ведётся разработка сюжета; детали текущих сцен остаются черновыми, пока не утверждены отдельно.
- **Следующая цель:** определить место хранения проекта и согласовать структуру материалов: сюжет, игровые сцены, персонажи, модели и техническая реализация.

### FOL-AI
- **Назначение:** потенциальное направление развития экосистемы IskraFOL.
- **Текущее состояние:** идея на раннем этапе; отдельный репозиторий и подтверждённый план работ не определены.
- **Следующая цель:** сформулировать назначение проекта и критерии, по которым станет понятно, стоит ли начинать реализацию.

## 4. Правила ведения реестра

Для каждого проекта указываются:
1. Название и назначение.
2. Ссылка на репозиторий или отметка, что он ещё не создан.
3. Текущий статус, подтверждённый проверкой.
4. Ближайшая конкретная цель.
5. Открытые PR, блокеры и непроверенные сценарии.
6. Дата последнего обновления карточки.

### Принципы достоверности
- Не считать задачу завершённой только потому, что она описана в PR или планах.
- Различать подтверждённые проверки и результаты, которые ещё предстоит воспроизвести.
- Не считать локальные изменения частью удалённого репозитория без проверки.
- Не изменять и не сливать проектные ветки без необходимого согласования.
- Обновлять статус после фактической проверки результата.
