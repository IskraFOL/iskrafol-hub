# IskraFOL — решение о перераспределении ресурсов (16 октября 2026)

## Утверждённое решение владельца

**Все доступные усилия по разработке переводятся на Minecraft-мод Four Old Legends.**
Это приоритет №1 и **единственный активно разрабатываемый продукт** до отдельного решения о возобновлении остальных работ.

## Статусы и рамки

| Направление | Текущий статус | Действия |
|---|---|---|
| **Four Old Legends / Old Legends** | **Active — полный приоритет** | Продолжить CI дорожного стенда, закончить аудит, устранить подтверждённые дефекты, добавить контент для Herobrine, NULL, Entity 303 и Лика; целевой крупный релиз **2.0.0** |
| **FOL Engine** | **Paused** | Оставить ветки, исходники и рабочую контрольную точку неизменными; новые задачи не начинать |
| **«Знакомое место» / The Familiar Place** | **Paused** | Сохранить историю, рабочее название, утверждённую карту Северного и существующие материалы; новый игровой контент пока не разрабатывать |
| **Four Old Legends Website** | **Paused** | Сохранить состояние сайта и имеющиеся ветки; не продолжать переработку без новой команды |
| **FOL-AI и другие инициативы** | **Deferred** | Идеи не удалять и не запускать сейчас |
| **IskraFOL Hub** | **Support only** | Обновлять карту, технические отчёты и контрольные точки **только для активной разработки мода**, не считать отдельной новой продуктовой разработкой |

Пауза — не отмена, не удаление и не решение о закрытии репозиториев. При возвращении к другим проектам следует продолжать с существующих контрольных точек, без повторного прохождения уже проверенных шагов.

## Последовательность работ по моду

1. Завершить проверку дорожных стыков на автоматически созданном Superflat/Creative мире: запуски GitHub Actions и фактическая геометрия NBT.
2. Закрыть проверенные дефекты и завершить технический аудит, не смешивая его с неподтверждёнными предположениями.
3. Провести инвентаризацию текущих игровых механик всех четырёх легенд.
4. Разработать новые события и объекты **для каждой из четырёх легенд**, регулярно проверять сборку и gameplay, не ограничиваться исправлениями.
5. После тестов и одобрения владельца подготовить крупную версию **2.0.0** (это целевая версия; сейчас ещё не выпускать).

Проверенные условия работы: отдельные ветки, черновые PR до решения владельца, автоматические тесты и артефакты GitHub Actions, отчёты в IskraFOL; не выполнять merge без явного разрешения.
