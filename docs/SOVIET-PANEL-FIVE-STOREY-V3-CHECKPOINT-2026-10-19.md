# КТ 19.10.2026 — Soviet Panel Five Storey V3 (кухни и крыша)

**Согласовано владельцем:** «Согласовываю всё» — адресный ремонт кухонь после ручного просмотра V2, сохранение двух крышных выходов, фасада и внутренних планировок, подготовка отдельной V3 для испытания.

## Источник и факт восстановления

- Найден настоящий исходный бинарный `soviet_panel_five_storey_v2_26_3.nbt` в Library (18.10.2026), размер 44 606 байт, SHA-256 `f3a7150397a567ea2fdc55fd5184ed01a8950681065a4d48431959371ec88b35`.
- README V2 пояснил четыре варианта квартир, декоративные коврики, тёплые светильники и **два перехода на крышу — по одному на подъезд**. Последние уже существовали в V2; никаких новых крышных лестниц V3 не строит.
- **Игровой фидбек пользователя по V2:** внутри видны коврики; кухонная мебель визуально выглядит как «один дубовый люк» вместо шкафчиков; два входа на крышу присутствуют. Это свидетельства ручного осмотра V2, не доказательство об игровом запуске V3.

## Что выполнено в V3

**Новое имя:** `soviet_panel_five_storey_v3_26_3.nbt` (файл V2 не заменяется).

- Из исходного V2 NBT изменены **40 кухонь**, а не генерирован новый дом с нуля.
- Кухни: в каждой нижние шкафы из бочек, навесные шкафы, печь или коптильня, котёл с водой как мойка, двухблочный холодильник с кнопкой-ручкой, небольшой стол и стул, подвесной фонарь, плиточный пол. 4 варианта расстановки/материалов.
- Фасад, балконы, все дверные блоки, кровати/коврики и существующие лестницы и крыша **не менялись**.
- Генератор полностью автономен (Python stdlib), комментарии на русском, требует строго SHA256 оригинальной V2, чтобы исключить ошибочный ввод.
- Сформирован `soviet_panel_five_storey_v3_26_3_TEST.zip`: V3 .nbt, README, генератор Python и резервная V2. Архив прошёл ZIP CRC-check; пользователь получает файл в чате.

## Следующий тест в Minecraft

1. Использовать копию мира и свободное место, в удалении от прежней V2 минимум 50–60 блоков; не разрушать действующие дороги/остановку.
2. Закрыть Minecraft, положить NBT в `<папка_мира>/generated/minecraft/structure/soviet_panel_five_storey_v3_26_3.nbt` (**structure**, единственное число), затем запустить через стандартную кнопку IntelliJ.
3. Разместить **один раз**: `/place template minecraft:soviet_panel_five_storey_v3_26_3 ~8 ~ ~8`.
4. Проверить визуально фасад, несколько кухонь разных этажей, прохождение от коридора к кухне, оба лестничных прохода к крыше, мебель, коллизии. При ошибке скриншот и координаты, исправлять адресно.
