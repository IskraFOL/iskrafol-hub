# BUS-STOP-01 — КТ отображения остановки, 17.10.2026

**Проект:** Four Old Legends, Minecraft 26.3 / Fabric / Java 25.
**Статус:** визуальный дефект материала воспроизведён; рабочее исправление ещё не согласовано. Кодовый [draft PR #56](https://github.com/Anwite/four_old_legends/pull/56) не слит в main.

## Причина возобновления
Владелец отметил, что после длительной борьбы с рябью остановка не была полностью принята визуально. Прошлая правка z-fighting разводила близкие грани и сохраняла исходные UV/атлас, но не закрывала общую задачу.

## Проверено исходниками
- Основной рендер: BusStopBuilder.java, одна ItemDisplay-сущность; команда /legends build bus_stop создаёт остановку в мире.
- Модель содержит **64 элемента, 384 грани**; **180 граней** используют плитку UV [0,0,4,4] исходного атласа 256×256. Эта плитка действительно содержит контрастные диагональные штрихи.
- Рабочий bus_stop_atlas.png и исходный bus_stop_atlas.original.png в main совпадают по Git blob SHA; ни один не перезаписывали.
- 18 пар частично совпадающих сонаправленных граней (без учёта повёрнутых) обнаружены на небольших деталях. Они могут давать локальный z-fighting, но не объясняют всю полосатость.

## BUS-STOP-02 — физическая коллизия ItemDisplay

По просьбе владельца автобусная остановка должна быть **физическим объектом, а не облаком**, через которое можно проходить. В main модель — ItemDisplay без собственной коллизии; замена одной только текстуры не решает вопрос.

- Открыт независимый [draft PR #57](https://github.com/Anwite/four_old_legends/pull/57), ветка feature/bus-stop-physical-collision, основанная на текущем main.
- Зарегистрирован **невидимый реальный Minecraft-блок** oldlegends:bus_stop_collision, хранится в мире как BlockState, а не как виртуальная картинка. Он формирует столкновения с фундаментом, четырьмя стойками, стеклянными стенками, лавочкой, наклонной крышей; передняя часть остаётся открытой.
- Блоки разбиваются на участки VoxelShape с учётом каждого из четырёх направлений остановки. Видимый ItemDisplay, оригинальный атлас и UV в физической ветке не менялись.
- Создание проверяет твёрдую опору и свободный объём, при частичной ошибке откатывает изменения; есть /legends bus_stop remove для удаления модели и её физической основы.
- [Java 25 compile GitHub Actions #39054438426](https://github.com/Anwite/four_old_legends/actions/runs/39054438426) — **SUCCESS** после корректировки типов свойств Minecraft 26.3.
- [Minecraft runtime #39054547074](https://github.com/Anwite/four_old_legends/actions/runs/39054547074) — **SUCCESS**: 138 блоков физики установлено в настоящем мире, 138/138 удалены. [Подтверждение 4 сторон #39055209815](https://github.com/Anwite/four_old_legends/actions/runs/39055209815) — **SUCCESS**: NORTH/EAST/SOUTH/WEST, пол, лавочка, навес — реальные VoxelShape, вход свободен, каждое удаление 138/138 + ItemDisplay, cleanup=true.
- Остаётся проверить сохранение и повторный вход, четыре поворота, соответствие VoxelShape визуальной модели и возможность свободно ходить внутри. После этого — визуальное согласование владельца. **Без merge в main.**

КТ с точными подтверждениями сохранена в [BUS-STOP-02-PHYSICAL-KT-2026-10-17.md](https://github.com/Anwite/four_old_legends/blob/feature/bus-stop-physical-collision/docs/BUS-STOP-02-PHYSICAL-KT-2026-10-17.md). Проверка сохранения/перезахода и визуальное согласование остаются открытыми; PR #57 **Draft**, без merge.\n\nВизуальный ремонт альфа-атласа — в отдельном [draft PR #56](https://github.com/Anwite/four_old_legends/pull/56); смешивать несогласованную текстуру с физической веткой пока не нужно.

## BUS-STOP-02 — доказательное сохранение и защита от пересечений

**Тестирование 17.10.2026, без слияния в main.**

- Save & Quit в настоящем Minecraft 26.3 теперь подтверждено: мир действительно записывается в `run/saves/FOL_CI_BusStopNormal/dimensions/minecraft/overworld/region/*.mca`; отдельная серверная команда `/save-all flush` в одиночном клиенте недоступна.
- В [прогоне #39056462879](https://github.com/Anwite/four_old_legends/actions/runs/39056462879) найден реальный формат BlockState-палитры Minecraft 26.3: строка, compound с пустым ключом (default state) либо compound с `id/properties`. Скрипт исправлен для чтения этих вариантов и допускает короткий завершающий сектор файла MCA.
- На сохранении из [#39056462879](https://github.com/Anwite/four_old_legends/actions/runs/39056462879) анализ показывает **135 из 138** физических блоков; три клетки в одном столбце заменились на `minecraft:cobblestone` (шестиблочный столб). Это соответствует типу события `HerobrineLegend.pillar`, но в журнале нет прямого подтверждения его вызова.
- На следующем сохранении из [#39057203166](https://github.com/Anwite/four_old_legends/actions/runs/39057203166) анализ показал **121 из 138**: 17 блоков основания оказались заменены дорожными материалами. Само сохранение есть, но игровая физика может быть повреждена независимо запускаемыми генераторами событий.
- В [физической ветке PR #57](https://github.com/Anwite/four_old_legends/pull/57) добавлены предварительные проверки пересечения: NBT-дороги/структуры отказывают до изменения мира, если целевой объём занят `oldlegends:bus_stop_collision`; булыжный столб Херобрина также не перезаписывает физическую остановку. Эти защиты требуют повторного игрового теста.
- [Minecraft guard CI #39058274070](https://github.com/Anwite/four_old_legends/actions/runs/39058274070) проверяет фактические четыре попытки построить road_segment поверх остановки, ожидает все 4 запрета и сохранение 138/138 коллизий.
- [Isolated MCA CI #39058082608](https://github.com/Anwite/four_old_legends/actions/runs/39058082608): отдельный проверочный мир с `allowGriefing=false` **только в CI**, для независимой оценки сохранения блоков без случайных сцен. Итог ещё должен быть проверен; успешная Java-компиляция не заменяет игровой тест.
- Добавлены невидимая модель и multipart blockstate для `bus_stop_collision`: Minecraft раньше жаловался на отсутствующие визуальные модели сотен состояний невидимого блока, хотя его физика работала. Требует проверки повторной загрузки ресурсов.

**Статус:** физическая форма в оперативном мире — **4/4 verified**; долговременное сохранение без вмешательства других механик, защита от пересечений и Save/Quit/reopen — **не приняты до новых результатов**. PR #56 (текстуры) и PR #57 (коллизии) остаются раздельными черновиками, main не менялся.
