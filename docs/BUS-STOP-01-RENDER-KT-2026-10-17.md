# BUS-STOP-01 — КТ отображения остановки, 17.10.2026

**Проект:** Four Old Legends, Minecraft 26.3 / Fabric / Java 25.
**Статус:** визуальный дефект материала воспроизведён; рабочее исправление ещё не согласовано. Кодовый [draft PR #56](https://github.com/Anwite/four_old_legends/pull/56) не слит в main.

## Причина возобновления
Владелец отметил, что после длительной борьбы с рябью остановка не была полностью принята визуально. Прошлая правка z-fighting разводила близкие грани и сохраняла исходные UV/атлас, но не закрывала общую задачу.

## Проверено исходниками
- Основной рендер: BusStopBuilder.java, одна ItemDisplay-сущность; команда /legends build bus_stop создаёт остановку в мире.
- Модель содержит **64 элемента, 384 грани**; **180 граней** используют плитку UV [0,0,4,4] исходного атласа 256×256. Эта плитка действительно содержит контрастные диагональные штрихи.
- Рабочий bus_stop_atlas.png и исходный bus_stop_atlas.original.png в main совпадают по Git blob SHA; ни один не перезаписывали.
- 18 пар частично совпадающих сонаправленных граней (без учёта повёрнутых) обнаружены на небольших деталях. Они могут давать локальный z-fighting, но не объясняют всю полосатость.

При исходном атласе полосы есть, при полностью непрозрачном однотонном — исчезают. Геометрия и тип отображения те же.

## Продолжение аудита 17.10.2026 — альфа-канал как воспроизводимая причина

- [Реальный Minecraft A/B #39048273364](https://github.com/Anwite/four_old_legends/actions/runs/39048273364): с оригинальным атласом — сильные диагонали, с полностью непрозрачным — исчезают (но контроль не сохраняет стекло и цвета).
- [Кандидат только на металлическую плитку #39048885254](https://github.com/Anwite/four_old_legends/actions/runs/39048885254): SUCCESS; металлический каркас визуально чище, однако диагонали на боковых панелях сохраняются.
- [Кандидат RGB металл + стекло #39050911750](https://github.com/Anwite/four_old_legends/actions/runs/39050911750): SUCCESS; изменение цвета стекла при сохранении старого альфа-канала **не удаляет** диагонали в стекле. Следовательно, корневая причина в значительной степени **в альфа-маске**, а не только в RGB.
- Проверка 256×256 PNG показала: во многих плитках яркие диагональные области имеют альфа **23–33**, тогда как фон плитки преимущественно 255; через диагональные области просвечивает небо/мир. Ранее обнаруженное локальное наложение некоторых граней отдельным эффектом не исключено.
- Создан `scripts/build_bus_stop_atlas_alpha_candidate.py` в ветке аудита: кандидат на **альфа-коррекцию** с сохранением RGB **всех** пикселей, всех UV/модели и полной нетронутости `bus_stop_atlas.original.png`; стеклянная плитка сохраняет равномерную полупрозрачность (alpha 178). Этот вариант **не внесён** в working atlas в репозитории.
- [Игровой тест alpha-only #39051431856](https://github.com/Anwite/four_old_legends/actions/runs/39051431856) запущен; до результата не объявлять визуальный фикс завершённым.
